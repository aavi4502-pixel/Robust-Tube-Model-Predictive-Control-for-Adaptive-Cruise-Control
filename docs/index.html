Core Theoretical Architecture

Mathematical guarantees proved in the manuscript and validated in simulation.

1. Instantaneous Step-0 Conditioning (Proposition 1)

Standard tube MPC computes nominal input $u_\xi$ and adds ancillary feedback $c_t$ outside the solver, causing the total applied command $u_{\mathrm{app}}(t) = u_\xi(0|t) + c_t$ to violate actuator rate limits. Our architecture directly constrains the first nominal decision:

$$u_{\xi,0|t} \in [u_{\min} - c_t, u_{\max} - c_t] \cap [u_{\mathrm{app},t-1} - \Delta u_{\max} - c_t, u_{\mathrm{app},t-1} + \Delta u_{\max} - c_t]$$

This guarantees analytical applied slew compliance: $|u_{\mathrm{app}}(t) - u_{\mathrm{app}}(t-1)| \le \Delta u_{\max}$ across all feasible nominal steps.

2. Trajectory-Dependent Uncertainty Propagation (Lemma 1)

Rather than imposing static worst-case bounds across all horizon steps, ellipsoidal disturbance bounds propagate recursively along nominal predictions under continuous powertrain lag $\tau_a = 0.5\text{ s}$ and zero-order hold discretization:

$$\bar w_i = \alpha_i \bar w_{\max}, \quad \bar\sigma_{i+1|t} = \lambda \bar\sigma_{i|t} + \frac{\alpha_i^2}{1-\lambda}$$

This reduces peak uncertainty from $22.15$ to $0.39$ during aggressive maneuvers, directly preventing input-interval collapse.

3. LMI-Verified Ancillary Feedback Selection (Theorem 1)

The ancillary gain $K_{\mathrm{opt}} = [1.2345, -0.5985, -1.2588]$ is synthesized via discrete Lyapunov dissipation LMIs with weighting $R=50$ (stored in data/stage44c_lmi_candidate.mat). It minimizes the input support coefficient:

$$g_u = \sqrt{K_{\mathrm{opt}} (P^{-1})_{11} K_{\mathrm{opt}}^\top} = 0.755533 \implies \sigma^* = \left(\frac{u_{\max}-u_{\min}}{2 g_u}\right)^2 = 13.2482$$

This expands the input admissibility collapse threshold by +21.66% over the baseline gain ($\sigma^* = 10.8893$) while reducing control total variation by 48.4%.

4. Slew-Invariant Fallback Execution (Proposition 2)

When aggressive headway deficits cause the nominal tightened constraint set to become empty, a deterministic rate-limited fallback controller executes monotonic deceleration:

$$u_{\mathrm{fallback}}(t) = \max(u_{\min}, u_{\mathrm{app}}(t-1) - \Delta u_{\max})$$

This guarantees inductive rate compliance ($|u_{\mathrm{app}}(t) - u_{\mathrm{app}}(t-1)| \le \Delta u_{\max}$) across all switching sequences, avoiding secondary vehicle plant excitation.
